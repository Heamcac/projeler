# Imperium 1453

Türkçe MVP iskeleti: Next.js frontend, NestJS backend, Prisma/PostgreSQL modeli ve seed verileri.

## Komutlar

```powershell
npm.cmd install
npm.cmd run typecheck
npm.cmd run dev:frontend
npm.cmd run dev:backend
```

Backend varsayılan port: `4000`

Frontend varsayılan port: `3000`

Prisma için `.env` içinde `DATABASE_URL` gerekir.
